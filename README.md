# Filtro – Coffee Shop Landing Page

A landing page for a fictional coffee brand, built with pure HTML and CSS.

**Live demo:** https://tutu-creator.github.io/Coffee-sayt/

## Features
- Fully responsive design for mobile, tablet and desktop
- Navigation bar with sign up / login and app download buttons
- Hero section with call-to-action
- Product cards with prices (Cappuccino, Mocha, Latte, Cold Java)
- Partner brands section
- Footer with link groups and social media icons

## Built With
- HTML5
- CSS3
